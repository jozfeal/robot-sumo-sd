# Pygame Demo
This project uses Python 3.12 to keep everyone's environment consistent.
Run the following commands in your terminal from inside the repository folder to set up the environment:

​```
py -3.12 -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install pygame-ce==2.5.8
​```

If the second command fails with a script execution error, run this first, then retry:

​```
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
​```
